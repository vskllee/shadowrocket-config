1，小火箭「场景模式」设置当切换为WI-FI时，自动切换针对「内地网络」的配置文件；当没有WI-FI，连接到香港或新加坡蜂窝网络时自动切换为对应配置文件；

2，「内地网络」配置文件内，基本上只包含AI相关的规则，其他尽量不加。要用YouTube或者X平台的话，走香港或新加坡移动蜂窝网络（合法国际漫游）；

3，IOS可以设置「快捷指令」，当打开YouTube或者X平台时，自动关闭WI-FI走香港新加坡蜂窝网络，当关闭YouTube或X平台后再自动连接WI-FI；

4，目标是尽可能的大陆网络环境下仅用于激活Siri AI用，其他任何境外软件统统自动关闭WI-FI走合法国际漫游蜂窝网络；

5，「内地网络」配置里的规则仅仅用于自动关闭WI-FI切换蜂窝网络的一瞬间请求DNS时候兜底！

6，蜂窝网络国际漫游合法，法律面前人人平等，如果国际漫游不合法，请把中国境内所有外国人统统抓起来！
